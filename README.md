# Church App

Application pour la gestion d'église.

## 📁 Structure du projet

- `churchapp-backend/` - Backend de l'application
- `churchapp-frontend/` - Frontend de l'application
- `CAHIER_DES_CHARGES.md` - Cahier des charges
- `ROADMAP.md` - Roadmap du projet

## 🚀 Démarrage rapide

### Backend

```bash
cd churchapp-backend
npm install
npm run dev
```

### Frontend

```bash
cd churchapp-frontend
npm install
npm run dev
```
